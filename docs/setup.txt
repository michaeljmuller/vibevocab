VibeVocab Setup
===============

Prerequisite: Docker (or Podman — see note below)


1. Clone the repo and enter the directory.

2. Create your environment file:

     cp src/docker/.env.example src/docker/.env

   Edit src/docker/.env and fill in at minimum:

   - Authentication: set SINGLE_USER=your@email.com for single-user mode, OR
     provide GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and BOOTSTRAP_USER for
     Google OAuth (see .env.example for instructions on creating OAuth credentials).

   - LLM: set LLM_API_KEY for AI-generated examples. Defaults to OpenAI
     (gpt-4o-mini). For Anthropic, also set LLM_PROVIDER=anthropic. For local
     Ollama, see the LLM section in .env.example.

   - TTS: set ELEVENLABS_API_KEY and TTS_VOICE_ID for audio. Leave blank to
     run without audio.

3. Start the services:

     docker compose -f src/docker/docker-compose.yml up   # from project root
     # or: cd src/docker && docker compose up

   On first start, the database schema is created automatically. No manual
   setup needed.

4. Open http://localhost:5001 (or the port set by APP_PORT in your .env)


Utility scripts
---------------
utils/db-shell.sh    Open a psql shell to the running database


Podman
------
Podman can be used in place of Docker. Set DOCKER=podman in your environment
(or in src/docker/.env) so the utility scripts use the right command:

  export DOCKER=podman
  podman compose -f src/docker/docker-compose.yml up

If you access any host-side services from containers, use host.containers.internal
instead of host.docker.internal.
